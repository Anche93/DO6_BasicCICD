# Basic CI/CD

##### В данном проекте на базе платформы GitLab разработан простой **CI/CD** для проекта на Си. Сборка, тестирование, развертывание. 
В **.gitlab-ci.yml** указан проект C3_SimpleBashUtils, который реализует Bash утилиты *cat* и *grep*.
##### Файлы, полученные после сборки (артефакты), сохраняются в произвольную директорию со сроком хранения 30 дней.
##### Настроены уведомления об успешном/неуспешном выполнении пайплайна через бота в Telegram.
